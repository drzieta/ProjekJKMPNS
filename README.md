# ProjekJKMPNS
Website Projek Akhir Pelajar diwujudkan sebagai pusat rujukan dan komunikasi antara penyelia dengan pelajar. Platform ini menghimpunkan panduan, jadual, makluman dan dokumen projek bagi memudahkan akses maklumat, memperjelas tugasan serta memastikan pelaksanaan projek lebih teratur, sistematik dan berkesan.
